# 067_ject_stageplay — 词根 ject = 抛；投

词根小剧场第二集。本集给模板新增了「投掷」动作一家（向前 / 向后 / 向内 / 向外），
因为 ject 的核心含义就是"抛"，四个前缀正好是四个方向 —— 前缀就是考点。

| 项目 | 内容 |
|---|---|
| 词根 | ject = throw，抛；投 |
| 考试 | 四级（CET-4） |
| 时长 | 约 18 秒，1080×1920，30 fps |
| 配乐 | pop-bounce，116 BPM，D 调 |

## 单词

| 单词 | 场景动作 | 拆分 | 含义 |
|---|---|---|---|
| project | throw-fwd（向前投） | pro 向前 + ject 抛 | 项目；投射 |
| reject | throw-back（往回扔） | re 向后 + ject 抛 | 拒绝；抛弃 |
| inject | throw-in（投进玻璃管） | in 向内 + ject 抛 | 注射；投入 |
| eject | throw-out（从箱子弹出） | e 向外 + ject 抛 | 弹出；喷射 |
