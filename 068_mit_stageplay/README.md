# 068_mit_stageplay — 词根 mit / miss = 送；寄

词根小剧场第三集，067 的直接续集，复用投掷四方向。
本集的考点小心思：词根在 dismiss 里会**变拼法**（mit → miss），总结板标题
直接写成「mit / miss = 送；寄」，把这个易错点摆在明面上教。

| 项目 | 内容 |
|---|---|
| 词根 | mit（异形 miss）= send，送；寄 |
| 考试 | 四级（CET-4）；emit 为拓展词（每集最多一个） |
| 时长 | 约 17.5 秒，1080×1920，30 fps |
| 配乐 | ukulele-pop，120 BPM，E 调（应号主要求，比前作更欢快） |

## 单词

| 单词 | 级别 | 场景动作 | 拆分 | 含义 |
|---|---|---|---|---|
| transmit | 四级 | throw-fwd（远远送出） | trans 穿过 + mit 送 | 传送；传输；传播 |
| admit | 四级 | throw-in（送进玻璃管） | ad 向 + mit 送 | 承认；允许进入 |
| dismiss | 四级 | throw-back（送走） | dis 离开 + miss 送 | 解散；驳回 |
| emit | 拓展 | throw-out（从箱子送出） | e 向外 + mit 送 | 发出；散发 |
